## Description 
**Be My Valentine** is an interactive, romantic web proposal built to ask that special question in a fun and tech-savvy way. It features playful animations and a "hard-to-get" logic where the "No" button runs away.

✨ **Key Features**:
- 🏃‍♂️ **Unclickable "No" Button:** The "No" button moves randomly whenever the cursor approaches it.
- 📈 **Growing "Yes" Button:** Every time "No" is attempted, the "Yes" button grows larger.
- 🎨 **Beautiful UI:** Styled with TailwindCSS, featuring a smooth welcome animation and cute GIFs.

## Installation <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="30">

### Option 1: Run Locally
Simply open the `index.html` file in any web browser.

### Option 2: Deploy with Nginx (VPS)
If you have a Linux server, you can deploy this automatically.

1. **Clone this project**
   ```bash
   git clone https://github.com/Ali-Mahdiyanjoo/Valentine.git
   cd Valentine

2. **Run the Deployment Script**
    ```bash
    chmod +x deploy.sh
    sudo ./deploy.sh
    ```

This will install Nginx, configure the site, and serve it on your IP address.
